# Programação Orientada a Objetos

Repositório destinado aos exercícios, atividades e projetos desenvolvidos na disciplina de Programação Orientada a Objetos (POO) do curso de Análise e Desenvolvimento de Sistemas — UDESC.

## 📚 Conteúdos

- Java (paradigmas, execução, etc.)
- java.lang
- Classes e Objetos
- Coleções
- Pilares da Orientação a Objetos

## 📂 Organização

Os exercícios estão organizados por pastas:

- `01-introdução` 
- `02-java.lang`
- `03-classes-e-objetos` 
- `04-coleções`
