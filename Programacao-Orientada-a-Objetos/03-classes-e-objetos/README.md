# Exercício – Estruturas de Seleção (`switch case`)

## Objetivo

Desenvolver um programa em Java utilizando blocos independentes de código (`switch case`).

O programa deve executar a operação correspondente à opção numérica informada como entrada, seguindo os requisitos descritos abaixo.

## 1. Leitura e classificação de um número

- Ler um número inteiro.
- Verificar se o número é maior que `10`.
- Imprimir:
  - `"MAIOR"`, caso seja maior que 10.
  - `"MENOR"`, caso contrário.

## 2. Manipulação de um número

- Ler um número inteiro.
- Verificar as seguintes condições:
  - Se for múltiplo de `2`, multiplicar o número por `5`.
  - Se for múltiplo de `3`, subtrair `1` do número.
  - Se não for múltiplo de `2` nem de `3`, não realizar nenhuma alteração.
- Imprimir o resultado final.

> **Atenção:** As duas condições devem ser verificadas independentemente. Portanto, se o número for múltiplo de 2 e de 3, ambas as operações deverão ser realizadas.

## 3. Leitura de palavras

- Ler um número inteiro positivo.
- Ler uma quantidade de palavras (`String`) igual ao número informado.
- Imprimir todas as palavras separadas por espaço, na ordem inversa à leitura (da última para a primeira).

## 4. Cálculo do Máximo Divisor Comum (MDC)

- Ler dois números inteiros positivos.
- Calcular o Máximo Divisor Comum (MDC) entre os dois números.
- Imprimir o resultado.

## 5. Soma de números

- Ler vários números inteiros.
- Continuar a leitura até que seja informado um valor que não seja um número.
- Calcular a soma de todos os números inteiros lidos.
- Imprimir a soma final.

## Observações e regras gerais

- Todas as impressões devem finalizar com quebra de linha.
- Caso seja informada uma opção fora do intervalo permitido (`1` a `5`) no `switch case`, o programa deve simplesmente encerrar a execução.

---

**Conceitos trabalhados:** Estruturas de seleção (`switch case`), estruturas condicionais (`if/else`), operadores aritméticos e relacionais, operadores lógicos, leitura de dados, manipulação de Strings, estruturas de repetição, vetores e cálculo do MDC.
