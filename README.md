# TADS-UDESC

Repositório com trabalhos, exercícios e projetos desenvolvidos durante o curso de
**Tecnologia em Análise e Desenvolvimento de Sistemas** na
**UDESC (Universidade do Estado de Santa Catarina)**, campus Joinville.

Aqui reúno o que venho construindo ao longo da graduação, organizado por disciplina,
com foco em lógica de programação, estruturas de dados e desenvolvimento de software.

| Pasta | Descrição | Tecnologias |

| [Linguagem-de-Programacao](./Linguagem-de-Programacao) | Exercícios e trabalhos de programação em C, incluindo análise de algoritmos de ordenação | C |
